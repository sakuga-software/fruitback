A visitor with no account edits the text of their own note while it is open, from the same browser. `POST /feedback/<id>/text` takes the key of the browser instead of a session, on a site that takes notes from anybody. Every check of a member's edit still applies: the author kept in the index, the open stage read again under the lock, and one place. The reply names the visitor « not verified », and a tracker gets the new text in that reply. Another browser, a missing key and a closed note are refused. An edit counts with the visitor's replies, 5 a minute. In the widget, the visitor's menu reads « Edit the text » with no « Move the note ». The note says « You can edit it until a member picks it up. », and the field says « Edited text is sent to Linear too ».
