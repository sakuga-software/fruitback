« Private mode » is now « Extension mode » (« mode extension » in French): the mode where the extension shows the widget on a site that embeds nothing. The popup and the options page offer « Extension · the extension shows the widget », the table of the sites says « Extension », and the messages of the popup, of the servers page and of « Who can leave a note » in the console use the new name. Team mode keeps its name. The stored value of a rule stays `private`, so a rule saved before and a rules file written by an older version work as before.
