How it works

  1. Point at it

    A reviewer clicks any element of the page. Nothing to describe: the selector, the component and the file come with it.

  2. Write the note

    One field. The note becomes an issue in Linear, in GitHub Issues, or in the workspace itself.

  3. See it move

    The pin stays on the page, coloured by the state of its issue, with the team's replies under the note.

On a site that embeds nothing, the browser extension puts the same widget on the page, for you only.

Does the extension work with both?

Yes. It talks to the worker you name: the Cloud's, or your own.

Who reads the notes?
