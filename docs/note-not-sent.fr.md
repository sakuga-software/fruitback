# Une note qui n’est pas partie (français)

Le widget a dit « Cette note n’a pas pu rejoindre l’équipe ». **Votre note n’est pas perdue.** Cette
page dit pourquoi, et quoi faire.

[Read in English](note-not-sent.md)

## Si vous avez écrit la note

Le site envoie ses notes vers un endroit d’un outil de suivi, par exemple un projet de Linear. Cet
endroit n’existe plus, ou il a changé de place. Seule l’équipe du site peut en choisir un autre.

1. Ne fermez pas la note. Son texte reste dans le champ du widget, dans ce navigateur.
2. Prévenez la personne qui vous a donné le lien de ce site. Dites-lui que les notes ne parviennent
   plus à l’équipe.
3. Quand elle vous dit que c’est réparé, ouvrez la note et renvoyez-la.

## Si vous faites partie de l’équipe du site

Un membre de l’espace de travail voit « Corriger dans la console » dans le widget, avec un lien vers
la page du site. Pour corriger :

1. Ouvrez la console, puis **Sites**, puis le site.
2. Sous « Où vont les notes », l’endroit indique « Action requise ».
3. Ajoutez la bonne équipe ou le bon projet, appuyez sur « Mettre par défaut », puis sur « Retirer » à côté de l’ancien endroit.

La cause habituelle : dans Linear, le projet du site est passé dans une autre équipe. Le site garde
l’ancienne équipe, et Linear refuse un projet qui n’est pas dans cette équipe. Choisissez l’équipe
qui a le projet maintenant.

Seul un propriétaire ou un administrateur de l’espace de travail peut changer l’endroit d’un site.
